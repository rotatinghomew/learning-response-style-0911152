# 学习体验追踪资料约定

资料全部是本地合成业务记录，不含真实个人信息。`term-a` 为完整版本，`term-b` 保持业务值不变而调整表行次序，用于检验分析是否不恰当地依赖到达顺序；`limited` 保留登记资料并移除一类观测，表示证据不足的版本。版本内容不可就地修改。

- `people`：业务唯一键为 `person`。
- `items`：业务唯一键为 `item`。
- `answers`：业务唯一键为 `person, wave, item`。
- `vignettes`：业务唯一键为 `vignette`。
- `vignette_answers`：业务唯一键为 `person, wave, vignette`。

answer 是 1 至 5 的有序等级，不是等距连续测量；缺行代表未答而非中性答案。reverse 只标记题意方向，不是已处理分数。固定情境的 order 只代表同一 trait 内的预期顺序，不给定距离，不保证每个人遵循此顺序。不同 trait 没有共同计量单位。person 跨轮稳定，site 和 group 是登记分组。

字段之外不能从示例的编号顺序或随机生成规律推导业务关系。涉及权重、相关范围、模型支撑的判断必须使用明确登记的字段和业务假设。
